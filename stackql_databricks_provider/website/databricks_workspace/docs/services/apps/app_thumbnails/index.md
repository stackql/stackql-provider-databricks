## `UPDATE` examples

<Tabs

<TabItem value="update">

Updates the thumbnail for an app.

```sql
UPDATE databricks_workspace.apps.app_thumbnails
SET 
app_thumbnail = '{{ app_thumbnail }}'
WHERE 
name = '{{ name }}' --required
AND deployment_name = '{{ deployment_name }}' --required
RETURNING
thumbnail;
```
</TabItem>
</Tabs>
